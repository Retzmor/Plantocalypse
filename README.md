# Plantocalypse

Juego de supervivencia desarrollado en Unity.

## 🎮 Descripción
Plantocalypse es un juego donde el jugador debe derrotar a los enemigos para sobrevivir.

## ⚙️ Características
- Sistema de interacción con el entorno
- Mecánicas básicas de supervivencia
- Eventos dentro del juego

## 🛠️ Tecnologías
- Unity
- C#

## 👨‍💻 Mi rol
Implementé la lógica del juego, interacción con objetos y manejo de eventos principales.
